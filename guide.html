학생 안내서: 바이브 코딩으로 SDG 문제를 푸는 AI 도구 만들기

한눈에 보기

SDG가 말하는 문제 하나를 골라, 그 문제를 줄이는 AI 도구(웹앱)를 직접 만듭니다. 도구는 글을 읽는 AI(자연어처리)나 사진을 보는 AI(이미지처리)이고, 안에는 인공신경망이 들어 있어요.

코드는 학교 계정 무료 제미나이가 써 줍니다. 나는 무엇을 부탁할지 정하고, 결과를 교과 개념으로 해석하고, 보고서에 내 말로 씁니다.

  1. 질문 세우기: 주제를 고르고, 교과 개념을 근거로 가설을 쓴다.
  2. 모으기 (A1~A3단계): 데이터를 받고, 살펴보고, 정리해서 학습 80% · 시험 20%로 나눈다.
  3. 숫자로 바꾸기 (1단계): 글은 TF-IDF, 사진은 미리 학습된 모델로 숫자 표를 만든다.
  4. 학습하고 분석하기 (2~7단계): 신경망을 설계·학습·튜닝하고, 시험을 딱 한 번 보고, 틀린 예를 분석하고, 내 말로 해석을 쓴다.
  5. 공개하기 (W1~W3단계): HTML 웹앱 파일을 만들어 제출하면 선생님이 반 웹앱 전시장에 올려 주고, 그 주소로 QR 코드를 만들어 친구가 직접 써 보게 한다.
  6. 옮기기: 보고서와 A1 포스터를 템플릿에 채우고 포스터로 발표한 뒤, 제미나이 대화 전체를 제출한다.

모든 부탁 문장은 노트북의 단계 카드(💬 부탁)에 들어 있어요. 이 안내서는 순서와 규칙을 설명합니다.

탐구 질문을 내 것으로 만드는 틀. 주제가 같아도 질문과 가설은 사람마다 달라야 합니다.

  1. 무엇을 나눌까: 나눌 종류를 내가 고른다. (예: 숲·초지·농지·주거지, 호우·한파·대설…)
  2. 왜 중요할까: SDG 세부 목표의 문장을 찾아 내 문제와 잇는다.
  3. 무엇을 예상할까: 교과 개념을 근거로 "어떤 종류끼리 헷갈릴 것이다"를 쓴다. (예: 대설과 한파는 같은 겨울 기단에서 함께 일어나 헷갈릴 것이다)
  4. 무엇을 바꿔 시험할까: 6단계에서 조건을 바꿔 볼 것을 정한다. (예: 재해 이름을 지우면? 흐린 사진이면? 학교에서 찍은 사진이면?)

노트북 단계를 4차시에 거의 끝내고, 5~8차시에 보고서·포스터·발표로 옮깁니다. 차시가 끝날 때 '끝나면 남는 것'이 있는지 확인하세요.

한 차시에 단계를 다 못 끝내도 괜찮아요. 다음 차시 처음 10분에 이어서 하고, 그래도 막히면 아래 teacher를 씁니다.

시작하기와 한 단계 하는 법

1차시 첫 10분: 노트북과 대화방 준비

  1. 내 주제 노트북을 Colab에서 열고 파일 → 드라이브에 사본 저장을 누른다.
  2. 사진 노트북은 런타임 → 런타임 유형 변경 → T4 GPU를 고른다(무료).
  3. 0번 준비 칸을 실행만 한다. 안의 코드는 고치지 않는다.
  4. 1번 설정 칸에서 나눌 종류(CLASSES), 웹앱 안내 문장(INFO), 프로젝트 제목을 내 것으로 고치고 실행한다.
  5. 학교 계정 제미나이에서 새 대화방을 하나 열고, 노트북 맨 위의 첫 메시지를 복사해 보낸다(설정 칸 내용을 함께 붙여 넣기). 대화방 이름은 SDG AI 프로젝트_출석번호로 바꾼다.

한 단계 = 늘 같은 다섯 동작

  1. 카드 읽기: 🎯 목표와 ✅ 나와야 할 것을 먼저 읽는다.
  2. 부탁 보내기: 💬 부탁을 통째로 복사해 대화방에 보낸다.
  3. 붙여 실행: 받은 코드를 👉 칸에 붙여 넣고 실행한다.
  4. 확인: check("단계")를 실행해 🎉가 나오는지 본다.
  5. 이해하고 적기: 🔍 이해 질문을 하나 이상 보내고, 📋 메모의 숫자를 보고서 메모에 옮긴다.

check와 teacher는 무엇을 하나요?

나오는 것 뜻 내가 할 일
🎉 통과 내 결과가 조건을 모두 지켰다 (코드 모양은 달라도 됨) 다음 단계로
⚠️ 경고 시험 자료가 새어 들어갔다, 변수 이름이 다르다 같은 문제를 찾았다 ⚠️ 문장을 그대로 대화방에 붙여 고쳐 달라고 한다
🆘 teacher("단계") 세 번 고쳐도 안 될 때 선생님 코드가 그 단계를 대신한다 다음 단계는 이어서 할 수 있다. 쓴 기록이 남으니 보고서 7장에 솔직하게 쓴다
  • teacher는 이미 통과한 단계에서는 아무것도 하지 않아요. 내 결과를 덮어쓰지 않습니다.
  • teacher("A1")은 인터넷에서 데이터를 대신 모아 주지 않아요. 선생님이 나눠 준 백업 파일(CSV 또는 사진 zip)을 왼쪽 📁에 올린 뒤 실행해야 하고, 출처(SOURCE)·이용 조건(LICENSE)은 직접 씁니다.
  • teacher("7")은 해석을 대신 쓰지 않고 쓰는 틀만 보여 줘요.
  • teacher는 기본 방법만 써요. 주제에 맞는 시험(예: 재해 이름 지우기)은 내가 AI와 해야 보고서에 쓸 수 있어요.

다음 시간에 이어서 할 때

  1. 내 드라이브의 노트북 사본을 연다.
  2. Colab을 닫으면 파일이 사라져요. 저장해 둔 raw_data.csv(또는 사진 zip)를 왼쪽 📁에 다시 올린다.
  3. 런타임 → 모두 실행을 눌러 지난 시간까지의 칸을 다시 실행한다.
  4. 같은 대화방에서 이어 간다. AI가 앞 내용을 헷갈리면 summary() 결과를 복사해 "지금까지 상황이야"라고 붙여 넣는다.

웹앱 만들기와 QR (W2 · W3)

웹앱은 HTML 파일로 만들어 선생님께 제출하고, 선생님이 반 웹앱 전시장에 올려 주면 그 주소로 QR을 만들어 포스터에 붙여요. GitHub 가입은 필요 없고, 수업이 끝나도 계속 열려 있어요.

  1. W2: 노트북 W2 카드의 부탁으로 webapp 폴더에 index.html과 모델 파일(글: model.json, 사진: model.onnx)을 만든다. check("W2")가 파이썬과 같은 답을 내는지 확인해 준다.
  2. 미리 보기: preview_webapp()으로 코랩에서 웹앱을 열어 본다. 글 주제는 화면 아래 "검산 통과"를 확인한다.
  3. 제출: make_zip("2-1-07")(내 반-번호)로 만든 zip을 클래스룸 '웹앱 제출'에 낸다.
  4. W3: 선생님이 알려 준 주소를 WEBAPP_URL에 넣고 QR을 만들어 포스터 ⑦칸에 붙인다. 주소도 글자로 적는다.

댓글 혐오 표현 주제는 공개 웹앱을 만들지 않아요. 수업 중 그라디오로만 시연하고, 포스터 ⑦칸에는 화면 캡처를 넣어요. 자세한 방법은 웹앱 만들기와 QR 안내와 따라 하기 캐러셀을 보세요.

규칙

AI 사용 규칙: 무료 제미나이 · 대화방 하나 · 대화 전체 제출

  1. 학교 계정의 제미나이 앱(gemini.google.com)만 씁니다. 유료 기능, 다른 AI, Colab 안의 AI 버튼은 쓰지 않아요.
  2. 1차시에 연 대화방 하나를 끝까지 씁니다. 사용량 제한에 걸려도 새 대화방을 열지 말고 기다리거나 teacher로 넘어갑니다. 어쩔 수 없이 새로 열었다면 선생님께 말하고 두 대화를 모두 냅니다.
  3. 대화에 이름·학번·학교·얼굴 사진 같은 개인정보를 쓰지 않아요.
  4. 보고서 문장을 AI에게 대신 쓰게 하지 않고, AI의 문장을 보고서에 옮기지 않아요. 7단계는 내가 먼저 쓰고, 그다음에만 "고치지 말고 근거가 부족한 곳을 질문으로 짚어 줘"라고 물어봅니다.
  5. 마지막에 대화 전체를 선생님이 안내한 방법(공유 링크 또는 PDF)으로 제출합니다.

데이터·사진 규칙

  1. 이용 조건 확인: 라이선스를 읽고 설정 칸의 SOURCE·LICENSE에 적는다. 보고서 2-1과 포스터 아래쪽에 그대로 쓴다.
  2. 천천히 요청: 웹 요청 사이에는 1초 이상 쉬고, 받은 데이터는 파일로 저장해 다시 받지 않는다.
  3. 개인정보 금지: SNS 글, 사람 얼굴이나 이름표가 나오는 사진은 모으지 않는다.
  4. 아무 사진이나 내려받지 않기: 공개 데이터나 내가 찍은 사진만 쓴다. 지도 서비스 화면 캡처는 쓰지 않는다.
  5. 백업 파일 받아 두기: API나 내려받기가 막히면 선생님의 백업 파일로 이어 간다.

주제별 특별 규칙

주제 꼭 지킬 것
재난문자 인증키(API_KEY)는 설정 칸에만 넣고 대화방·보고서·웹앱에 쓰지 않는다. 실종자 안내처럼 사람 정보가 담긴 문자는 지운다.
댓글 혐오 표현 화면에는 앞 14글자만 보여 준다. 혐오 문장을 새로 만들지 않는다. 웹앱에 예시 문장을 넣지 않는다. 데이터를 퍼뜨리지 않는다. 공개 웹앱을 만들지 않는다.
분리배출 사람이 나오지 않게 찍는다. 직접 찍은 사진은 zip으로 내려받아 둔다.
위성 사진 직접 구한 위성 사진을 더할 때는 이용 조건을 먼저 선생님께 보여 드린다.

자주 나오는 말

말 뜻 이렇게 읽는다
API 프로그램이 다른 서비스에 데이터를 요청하는 창구 인증키는 비밀번호처럼 다룬다
라이선스 데이터를 쓸 수 있는 조건 (CC BY, MIT, 공공누리 등) 출처를 밝히는 것은 기본
TF-IDF 낱말이 그 글에서 얼마나 중요한지 나타내는 숫자 그 글에 자주, 다른 글에 드물게 나오면 큼
전이학습 미리 학습된 신경망의 '눈'을 빌려 쓰는 방법 사진 한 장이 숫자 수백~천여 개가 된다
파라미터 신경망이 학습으로 정하는 숫자(가중치와 편향) 입력 수 × 뉴런 수 + 뉴런 수
검증 자료 학습 중 실력을 재려고 학습 자료에서 떼어 둔 부분 튜닝은 이것으로만 한다
시험 자료 마지막에 딱 한 번 채점하는 자료 결과를 보고 설정을 바꾸지 않는다
학습 곡선 반복마다 loss와 val_loss가 어떻게 변했는지 val_loss가 다시 오르면 과대적합
과대적합 학습 자료를 외워 새 자료에서 오히려 틀리는 상태 EarlyStopping으로 막는다
데이터 누수 시험 자료의 정보가 학습에 섞여 점수가 부풀려지는 일 check가 ⚠️로 알려 준다
정확도 전체 중 맞힌 비율 무작위(1 ÷ 종류 수)와 비교한다
혼동행렬 실제(줄)와 예측(칸)의 개수표 대각선 = 맞힌 것, 나머지 = 헷갈린 쌍
재현율 실제 그 종류 중 맞힌 비율 낮으면 그 종류를 자주 놓침
강건성 조건이 바뀌어도 성능이 유지되는 정도 6단계 조건 바꾼 시험으로 확인
