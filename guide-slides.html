2차시 · 1단계 · 글을 숫자로 (TF-IDF)

학습 문자로만 단어장 2,146개를 만들었어요

💬 보낸 부탁 (줄임)

[1단계] 형태소 분석기 kiwipiepy로 낱말을 쪼개는 함수를 만들고, TfidfVectorizer를 texts_train으로만 fit, texts_test는 transform만 해 줘. X_train, X_test로 저장해 줘.

✅ 결과 → check("1") 🎉

X_train (1,523, 2,146) · 문자 1개 = 숫자 2,146개

✏️ 이해 질문으로 정리

TF = 이 문자에 그 낱말이 얼마나 자주 나오나
IDF = 전체 문자 중 얼마나 드문가
→ ‘안전’은 작고, ‘동파’는 크다

✏️ 단위를 고른 이유

재난문자는 맞춤법이 정확한 행정 문장이라 형태소 낱말이 뜻을 잘 담는다.

📝 보고서 3장 · check는 단어장을 학습 글로만 다시 만들어 비교해요. 시험 글을 넣었으면 ⚠️가 나와요.

2차시 · 2단계 · 신경망 설계

입력 2,146 → 은닉 64 → 출력 6

💬 보낸 부탁 (줄임)

[2단계] Keras로 model을 만들어 줘: Input → Dense 64(relu) → 출력층 len(class_names)개(softmax). model.summary()를 보여 줘. 아직 학습은 하지 마.

✅ 결과 → check("2") 🎉

파라미터 137,798개

✏️ 직접 계산해 봄

은닉층: 2,146 × 64 + 64 = 137,408
출력층: 64 × 6 + 6 = 390
합계: 137,798 ✔

✏️ 배운 개념과 연결

softmax = 로지스틱 회귀를 6종류로 넓힌 것. 은닉층이 낱말들의 조합을 배운다.
