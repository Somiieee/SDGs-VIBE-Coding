HTML 웹앱 기술 안내 (교사용)

학생 웹앱은 서버 없이 브라우저 안에서 신경망을 계산하는 HTML 파일이에요. 그래서 GitHub Pages 같은 무료 정적 호스팅에 올려 두면 노트북을 꺼도, 학기가 끝나도 계속 열려 있어 포스터 QR이 깨지지 않아요. 이 페이지는 그 원리와 확인 방법을 정리한 것이에요.

왜 HTML 방식인가

방식 계속 열림 비용 학생 계정 비고
그라디오 share 링크 아니요 (노트북이 켜져 있을 때만, 최대 72시간) 무료 필요 없음 수업 중 시연용
허깅페이스 그라디오 Space 예 유료 요금제 필요 필요 현재 무료 계정으로는 어려움
HTML + GitHub Pages (선생님 저장소) 예 무료 (공개 저장소) 필요 없음 이 수업의 기본 방식

GitHub Pages는 공개 저장소면 무료이고, 사이트 하나에 1GB까지 올릴 수 있어요. 학생 웹앱은 글 모델 1MB 안팎, 사진 모델 10~20MB라서 한 학년 정도가 들어가요.

글 웹앱: model.json

1단계의 TF-IDF(글자 조각 char_wb, 2~3글자)와 2단계 신경망의 가중치를 JSON 파일 하나로 내보내고, index.html의 자바스크립트가 사이킷런과 똑같은 방법으로 계산해요.

  1. 글을 소문자로 바꾸고 띄어쓰기로 낱말을 나눈다.
  2. 낱말 앞뒤에 공백을 붙이고 2~3글자 조각으로 자른다. 낱말이 조각보다 짧으면 낱말 전체 하나만 쓴다.
  3. 조각 수로 (1 + ln(개수)) × idf를 구하고 L2 정규화한다.

  4. Dense 층을 차례로 계산한다 (relu → softmax).

  5. model.json 안의 tests(시험 글 5개와 파이썬 확률)로 페이지가 열릴 때 스스로 검산하고, 화면 아래에 "검산 통과"를 보여 줘요.

  6. 1단계를 형태소(word) 방식으로 한 학생은 브라우저에서 형태소 분석을 할 수 없어서, 웹앱용 글자 조각 모델을 한 번 더 학습해 내보내요. 보고서에는 원래 모델 숫자를 쓰게 지도해 주세요.

사진 웹앱: model.onnx

전처리 → 1단계의 사전학습 모델(base) → 학생 신경망을 keras 모델 하나로 묶어 ONNX 파일로 저장하고, 브라우저에서는 onnxruntime-web이 계산해요.

  • 입력: 사진 크기(보통 224×224) × RGB, 숫자 0~255 그대로. 전처리(예: −1~1로 바꾸기)는 모델 안에 들어 있어요.
  • keras 3의 model.export(..., format="onnx")를 쓰고, tf2onnx가 필요해요.
  • 저장 전에 예측을 한 번 해야 해요. 바로 export하면 "The model provided has never called" 오류가 나요. 노트북 부탁 문장에 반영되어 있어요.
  • MobileNetV2 기준 파일 크기는 약 9MB였어요. GitHub 웹 업로드는 파일 하나에 25MB까지예요.

시험한 결과

이 방식은 노트북 6개를 처음부터 끝까지 실행하고, 만든 웹앱을 휴대폰 크기의 실제 브라우저(Chromium)로 열어 시험했어요.

  • 글 웹앱: 브라우저 확률과 파이썬 확률이 사실상 같았고(차이 0.0000001 이하), 화면에 "검산 통과 5/5"가 나왔어요.
  • 사진 웹앱: 브라우저와 파이썬(onnxruntime)의 차이가 0.0000001 이하였어요. 실제 MobileNetV2 구조로도 차이 0이었어요.
  • 일부러 망가뜨린 파일(가중치 바꿔치기, 파일 추가, 인증키 포함, 전처리 누락)은 check("W2")가 모두 잡아냈어요.
  • 실제 제미나이가 부탁 문장대로 코드를 짜는지는 수업 전에 한 번 돌려 보시길 권해요.

올리는 곳

학생 웹앱은 선생님의 반 웹앱 저장소에 반-번호 폴더로 올려요. 만드는 방법과 점검표는 교사용 페이지의 "반 웹앱 저장소"와 템플릿 zip의 README에 있어요.
