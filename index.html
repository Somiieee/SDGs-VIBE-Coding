W2 · W3

웹앱은 선생님이 올려 줘요

GitHub 가입은 필요 없어요. HTML 웹앱을 만들어 제출하면 선생님이 반 웹앱 전시장에 올려 주고, 그 주소로 QR을 만들어 포스터에 붙여요. 수업이 끝나도 계속 열려 있어요.

  1. W2 만들기제미나이에게 부탁해 webapp 폴더에 index.html과 모델 파일(글: model.json, 사진: model.onnx)을 만들어요.
  2. 미리 보기코랩에서 웹앱을 열어 보고, 파이썬과 웹의 확률이 같은지 검산해요.
  3. 제출webapp 폴더를 반-번호.zip(예: 2-1-07.zip)으로 압축해 클래스룸에 내요.
  4. W3 QR선생님이 알려 준 주소로 QR을 만들어 포스터 ⑦칸에 붙이고, 주소도 글자로 적어요.

이름 · 학교 · 얼굴 사진, 인증키, 데이터 파일은 웹앱에 넣지 않아요. 댓글 혐오 표현 주제는 공개하지 않고 수업 중 그라디오 시연만 해요. 노트북에서는 preview_webapp()으로 미리 보고 make_zip("반-번호")로 제출 파일을 만들어요.
