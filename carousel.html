W2 · 글 주제

노트북 W2 카드의 부탁을 복사해요

1. 내 설정에 맞는 부탁 하나 고르기

ANALYZER = "char" 이면 글자 조각 부탁

ANALYZER = "word" 이면 형태소 부탁
(웹앱용 글자 조각 모델을 하나 더 학습해요)

2. 대화방에 보내고 받은 코드를 노트북 코드 칸에 붙여 실행

부탁에 들어 있는 것

  • model.json 모양 (단어장, 가중치, 검산용 글)
  • 브라우저에서 똑같이 계산하는 방법
  • 검산 통과 / 실패 표시
  • 서버 · API 키 쓰지 않기

형태소 방식이었다면, 웹앱용 모델의 시험 정확도가 따로 나와요. 보고서에는 원래 모델 숫자를 쓰고, 웹앱 숫자는 6-6에 함께 적어요.

  • 주제 제목
  • 쓰는 방법
